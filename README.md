## 📌 Description

A simple Python-based **Employee Management System** that demonstrates important **Object-Oriented Programming (OOP)** concepts such as inheritance, encapsulation, constructors, method overriding, and destructors.

## ✨ Features

* Create and store a **Person**.
* Create and store an **Employee** with Employee ID and Salary.
* Create and store a **Manager** with Department details.
* Display details of Person, Employee, or Manager.
* Demonstrates **inheritance** between Person → Employee → Manager.
* Demonstrates **encapsulation** using private Employee ID and Salary.
* Uses **getter and setter methods** to access private data.
* Uses `issubclass()` to check inheritance.
* Menu-driven console interface.

## 🛠️ OOP Concepts Used

* **Class & Object**
* **Constructor (`__init__`)**
* **Inheritance**
* **Encapsulation**
* **Method Overriding**
* **Destructor (`__del__`)**
* **Getter and Setter Methods**
* **`super()` Function**
* **`issubclass()` Function**
